# はじめまして。創業1934年、市川のお花屋さん「フラワーセンターウチダ」です

はじめまして。
千葉県市川市のお花屋さん「フラワーセンターウチダ」の【お名前・ニックネーム】です。
このnoteを開いてくださって、ありがとうございます。

フラワーセンターウチダは、1934年（昭和9年）に創業しました。
1972年からはJR市川駅直結の「シャポー市川」にお店を構え、90年以上にわたって、市川の街でお花をお届けしてきました。

長いあいだ私たちのお店を支えてくださった地域の皆さまに、心から感謝しています。
そして、お花に囲まれた私たちの毎日を、もっとたくさんの方に知っていただきたい。
そう思って、noteを始めることにしました。

---

## フラワーセンターウチダのこと

- **創業**：1934年（昭和9年）
- **場所**：JR市川駅直結「シャポー市川」内（1972年から）
- **私の担当**：【例：店頭での接客と、アレンジメントづくり】

駅に直結しているので、お仕事帰りやお出かけのついでに、ふらりと立ち寄っていただけるのが私たちのお店のよいところです。

創業から90年以上。
街の景色も、お店に並ぶお花の種類も少しずつ変わってきましたが、「地域の皆さまの毎日と、大切な節目に寄り添いたい」という想いは、ずっと変わらずに受け継いできました。

## 街の「大切な日」に、お花を

おかげさまで、個人のお客さまだけでなく、市内の学校や市役所、地元の企業の皆さまからも、ご注文をいただいています。

入学式や卒業式、開店や就任のお祝い、そしてご葬儀やお供えのお花まで。
冠婚葬祭のさまざまな場面で、お手伝いをさせていただいています。

うれしい日も、悲しい日も、人生の節目にはお花があります。
その大切な場面を任せていただけることを、とてもありがたく、そして誇りに思っています。

## お花屋さんの毎日

もちろん、特別な日だけではありません。

誕生日のプレゼントや、ちょっとしたお礼、
「今日はなんとなく、部屋にお花を飾りたくて」という日。
お客さまがお花を選ぶ理由はさまざまで、そのひとつひとつに小さな物語があります。

仕入れたばかりのお花の水あげをして、状態を確かめながら店頭に並べていく。
そして、お花を受け取ったお客さまの表情が、ふっとやわらぐ。
その瞬間に立ち会えることが、この仕事のいちばんの喜びです。

## これから書いていきたいこと

このnoteでは、こんなことをお届けしていく予定です。

1. **季節のお花の紹介** … いまの時期に入ってくるお花や、その魅力
2. **お花を長く楽しむコツ** … 水の替え方や切り戻しなど、おうちでできるちょっとした工夫
3. **お祝い・お供えのお花選び** … 場面ごとのお花の選び方や、ちょっとしたマナー
4. **お店の裏側** … 仕入れや水あげ、アレンジメントができるまでの様子
5. **90年の歴史と、市川の街のこと** … 創業当時からの思い出や、駅前の今と昔

お花に詳しくない方にも、気軽に読んでいただけるような記事にしていきたいと思っています。
